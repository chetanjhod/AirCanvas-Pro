# 🎨 AirCanvas Pro

An AI-powered virtual drawing studio that lets you draw in the air using hand gestures.

## ✨ Features

- Real-time hand tracking
- Air drawing using finger gestures
- Custom brush colors and sizes
- Eraser, Undo and Redo
- Download artwork as PNG
- Premium dark user interface

## 🛠️ Technologies

- Python
- Streamlit
- MediaPipe
- OpenCV
- NumPy
